### ISC2 CC — Certified in Cybersecurity

| Campo      | Detalhe                              |
| ---------- | ------------------------------------ |
| Custo      | **Gratuito**                         |
| Nível      | Entry-level                          |
| Validade   | 3 anos (15 CPEs/ano para manutenção) |
| Prazo alvo | Mês 2 (Julho 2025)                   |
| Status     | ⬜ Não iniciado                      |

**Por que agora:** Reconhecimento global da ISC2, sem pré-requisito de experiência, estuda conceitos que você já usa no trabalho. É o sinal mais rápido de credibilidade que você pode emitir.

**Plano de estudo:**

- [ ] Criar conta em https://www.isc2.org/certifications/cc
- [ ] Completar o curso oficial gratuito (aprox. 14h)
- [ ] Fazer 2 simulados com nota ≥ 80% antes de agendar
- [ ] Agendar o exame (Pearson VUE — online ou presencial)
- [ ] Adicionar ao LinkedIn após aprovação

**Recursos:**

- Curso oficial ISC2: https://www.isc2.org/certifications/cc/cc-certification-self-study-resources
- Simulados: https://www.pocketprep.com/exams/isc2-cc/

#### eJPT — eLearnSecurity Junior Penetration Tester

| Campo      | Detalhe                                            |
| ---------- | -------------------------------------------------- |
| Custo      | ~R$ 1.100–1.300 (≈ $200 USD)                       |
| Nível      | Entry/Junior — prova 100% hands-on                 |
| Formato    | Exame em ambiente de lab real, sem multiple choice |
| Validade   | 3 anos                                             |
| Prazo alvo | Mês 12 (Jul/2026)                                  |
| Status     | ⬜ Não iniciado                                    |

**Por que o eJPT:** É a melhor relação custo-benefício em pentest/AppSec para júnior. A prova é prática — você recebe um ambiente real e tem de comprometer máquinas. Isso diferencia de qualquer certificação teórica.

**Plano de estudo:**

- [ ] Criar conta na INE Security: https://security.ine.com
- [ ] Completar o path gratuito "Starter Pass" (fundamentos de pentest)
- [ ] Completar o curso pago eJPT (incluído no voucher do exame)
- [ ] Praticar em TryHackMe — path "Jr Penetration Tester"
- [ ] Praticar em HackTheBox Starting Point (gratuito)
- [ ] Fazer pelo menos 10 máquinas no HackTheBox ou TryHackMe antes do exame
- [ ] Agendar exame quando taxa de acerto em labs for ≥ 75%

**Recursos:**

- INE Security: https://security.ine.com/certifications/ejpt-certification/

| Campo         | Detalhe                                                         |

| Nome sugerido | `appsec-testing-framework`                                      |
| Stack         | Python · Docker · OWASP ZAP API · Semgrep · Trivy · HTML report |

**Critérios de conclusão:**

- [ ] Executa SCA com Trivy
- [ ] Gera relatório HTML consolidado com: sumário executivo, findings por severidade, mapeamento OWASP Top 10, recomendações de remediação

- [ ] Arquivo `LEARNING.md` com o que aprendeu
