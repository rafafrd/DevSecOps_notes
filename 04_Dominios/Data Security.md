# 🗄️ Data Security

**Relacionado:** [[04_Dominios/Cloud Security]] · [[04_Dominios/Gestão de Risco]]

## Conceitos
- **DLP (Data Loss Prevention):** detecta ou bloqueia a saída indevida de dados sensíveis (e-mail, endpoint, cloud)
- **DSPM:** descobre e classifica dados sensíveis na cloud (onde estão e quem os acessa)
- **WAF:** filtra tráfego HTTP malicioso antes da aplicação. Complementa o AppSec, mas não substitui a correção
- **DAM (Database Activity Monitoring):** auditoria de acesso a bancos de dados

## Ferramentas citadas
- **Imperva:** Data Security (DAM), Cloud Security, WAF
- Nativas da cloud: Macie (AWS), Purview (Azure), Sensitive Data Protection (GCP)
